# 实验03、04补充资料：合并到已有学生实验包

## 下载与放置

此补充包对应已发布的Windows学生实验包v1.0.0，包含实验03、04及新增数据和代码，不包含独立运行环境。

1. 先准备好原学生实验包，找到含有 `notebooks`、`data`、`src`、`02_启动实验.cmd` 的根目录。
2. 将补充ZIP中的 `notebooks`、`data`、`src`、`config`、`docs` **合并复制到该根目录**。合并同名文件夹，保留里面已有文件；不要删除或整目录替换原data、src、notebooks。
3. 原notebooks目录中应同时看到 `modis_phenology_methods.ipynb`、`03_hls_phenology_comparison.ipynb`、`04_modis_change_climate_analysis.ipynb`。
4. 使用原来的启动入口打开JupyterLab，选择新增Notebook，从顶部运行。若正在运行Jupyter，请重启相应内核后再执行。

也可在仓库首页点击Code → Download ZIP，解压后将上述五个目录合并到实验包根目录；仓库根目录本身不是独立运行包，不要直接用它启动实验。补充ZIP的根层就是这五个目录，没有额外包装层。

## 内容

- 实验03：HLS物候、平滑方法、自然植被和作物比较；输入在data/hls，固定展示点在config。
- 实验04：多年绿度、物候、恢复监测和气候关系；复用原包data/beijing_modis，新增气候数据在data/beijing_terraclimate。
- src/vegetation_lab：四个新增支持模块；其余共用模块来自原学生包。

本补充包不携带运行结果，不覆盖原始MODIS数据，也不修改原实验Notebook或启动设置。重复合并会覆盖同名03/04文件；已修改的Notebook请先另存。

## 实验04的输入边界

完整物候空间趋势及SOS/EOS气候相关依赖原物候实验生成的完整2001—2025年DL空间结果。原学生包全区多年开关默认关闭，仅运行当年空间图不能替代完整多年结果。没有完整结果时，对应图显示待计算；年度绿度、区域平均物候及可用气候分析仍可执行。

气候数据随源材料提供2001—2024年，气候相关按共同年份配对，不伪造2025年数据。相关不代表因果。

## 环境

已发布Windows v1.0.0含本补充实验所需依赖，无需联网安装。Mac基础包目前未公开发布，且其精简环境未包含实验04所需pymannkendall和可选STL所需statsmodels；本补充包不宣称在该Mac环境中直接可用。
